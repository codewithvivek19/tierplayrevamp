# ADR-012 — Battlez reference visual system

The user's explicit request for the Battlez template visual language supersedes ADR-011's procedural homepage opening. The live reference was inspected through the browser at 1440px: Inter, #060914 background, #9DC0E3 headings, #D3E1EF body, 90px hero and 50px section headings, dark beveled buttons, clipped upper-right card corners and subtle grain/gradient surfaces.

Implement that visual language using Tierplay's original logo, existing game and cabinet imagery, content structure and route destinations. Map reference benefits to Tierplay's entrance/floor/cabinets; feature timeline to Altitude/Pinnacle; store cards to the six game detail routes; closing orbit to the Tierplay contact CTA. Do not introduce template prices, cart transactions, invented testimonials or partner logos.

Preserve procedural hero source as historical work. The current homepage uses semantic image/HTML content with GSAP entrance/parallax enhancement and reduced-motion fallback; no GLB is required. Real film/model locations remain labelled placeholders.

Validation completed after preview access was restored: production build, typecheck, 10 focused Chromium tests and desktop/mobile screenshot review. See docs/review/BATTLEZ-REVIEW-2026-09-27.md. These are new revision-specific results, separate from the prior hero tests.
