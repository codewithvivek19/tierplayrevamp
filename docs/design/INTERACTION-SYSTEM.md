# Interaction System

Draft. A cabinet is idle, focused or selected; hover and keyboard focus expose same metadata. Tap focuses, labelled Enter selects. Enter/Space activate controls, Escape cancels focus/inspection, native navigation always reachable. No model scale on hover. Forms use visible labels, required indicators, inline errors plus error summary, pending and genuine server success. Menu closes with Escape and returns focus; modals, if used, trap focus and restore it. No canvas-only controls.
